  - title: Track

  - title: Alert
    details: Receive HMAC-signed webhook events the moment a commitment changes state, fulfilled, overdue, contradicted, or cancelled.
  - title: Integrate
    details: Python and TypeScript SDKs, or call the REST API directly. Works with any LLM framework, email client, or support tool.
